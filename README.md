# NOVA Music 8

پخش‌کنندهٔ موسیقی محلی ویندوز با کتابخانهٔ SQLite، موتور PCM، اکولایزر و پیشنهاددهندهٔ آفلاین Smart DJ.

## امکانات

- رابط تیره با PySide6، جستجو، علاقه‌مندی‌ها و اسکن پوشه
- پخش، مکث، جلو و عقب، تکرار، Shuffle و اکولایزر ۱۰ بانده
- رمزگشایی محلی با FFmpeg و نمایش طیف زنده
- Smart DJ با حالت‌های Favorites، Balanced و Discovery
- ثبت محلی شروع، مکث، ادامه، زمان واقعی شنیدن، تکمیل، رد، توقف و علاقه‌مندی‌ها
- امتیازدهی تدریجی و قابل‌توضیح با کاهش اثر تکرار و پخش‌های قدیمی
- پروفایل ژانر، خواننده و آلبوم، نمایش تاریخچه و آهنگ‌های بیشتر شنیده‌شده/ردشده
- تنظیم تنوع صف، حذف پیشنهاد و افزودن سریع آن به علاقه‌مندی‌ها

## پیش‌نیازها

- Python 3.12 یا جدیدتر
- FFmpeg در `PATH` یا فایل محلی `nova_music/bin/*/bin/ffmpeg.exe`
- دستگاه خروجی صوتی ویندوز

## نصب و اجرا (PowerShell)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## استفاده از Smart DJ

1. آهنگ‌ها را از صفحهٔ کتابخانه اضافه کن. ژانر، سال و شمارهٔ قطعه از برچسب فایل خوانده می‌شوند؛ برای اصلاح دستی روی آهنگ راست‌کلیک کن.
2. وارد صفحهٔ Smart DJ شو و حالت Favorites، Balanced یا Discovery را انتخاب کن.
3. میزان تنوع را تنظیم و «ساخت / بازسازی صف» را بزن. تحلیل در پس‌زمینه انجام می‌شود و آهنگ فعلی قطع نمی‌شود؛ صف هوشمند پس از آن پخش خواهد شد.
4. روی پیشنهاد دوبار کلیک کن تا همان آهنگ پخش شود؛ از دکمه‌ها یا منوی راست‌کلیک برای علاقه‌مندی و حذف پیشنهاد استفاده کن.

ثبت تاریخچه به‌طور پیش‌فرض فعال است و فقط در پایگاه دادهٔ محلی کاربر ذخیره می‌شود (`%LOCALAPPDATA%\NOVA Music\library.sqlite3`). خاموش‌کردن ثبت، تاریخچهٔ قبلی را نگه می‌دارد؛ دکمهٔ «پاک‌کردن تاریخچه» آن را حذف می‌کند. شنیدن بر اساس فریم‌های تحویل‌شده به خروجی صوتی محاسبه می‌شود، نه جابه‌جایی نوار Seek. زمان شنیدن دوره‌ای ذخیره می‌شود تا با بسته‌شدن ناگهانی برنامه از دست نرود.

مهاجرت Smart DJ فقط ستون‌ها، جدول‌ها و ایندکس‌های افزایشی می‌سازد؛ جدول کتابخانهٔ موجود بازسازی یا پاک نمی‌شود.
