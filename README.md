# NOVA Music 8

نسخه ۸ بر پایه نسخه ۷ ساخته شده و روی دقت موقعیت پخش، نمایش طیف زنده و مدیریت بهتر موتور صوتی تمرکز دارد.

## امکانات
- رابط تیره و مدرن با PySide6
- کتابخانه محلی SQLite، جستجو و علاقه‌مندی‌ها
- افزودن فایل یا اسکن بازگشتی پوشه
- کنترل پخش، مکث، جلو/عقب، صدا، تکرار و Shuffle
- موتور صوتی PCM با `sounddevice` و رمزگشایی فایل‌ها با FFmpeg
- اکولایزر ۱۰ بانده
- نمایشگر طیف ۲۴ بخشی متصل به FFT سیگنال در حال پخش
- محاسبه موقعیت پخش بر اساس تعداد فریم‌های تحویل‌شده به خروجی صوتی، به‌جای افزایش تخمینی تایمر
- جلوگیری از چندبار اعلام پایان آهنگ و بی‌اعتبارسازی رشته‌های قدیمی رمزگشایی هنگام تعویض آهنگ
- گزارش وضعیت/خطاهای دستگاه صوتی در رابط

## پیش‌نیازها
- Python 3.12 پیشنهاد می‌شود.
- FFmpeg باید جداگانه نصب شده و در PATH ویندوز باشد. با `ffmpeg -version` بررسی کن.
- اتصال به دستگاه خروجی صوتی ویندوز لازم است.

## نصب و اجرا (PowerShell)
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## نکات و محدودیت‌ها
- این نسخه از نظر نحوی بررسی شده، اما در این محیط روی ویندوز و دستگاه صوتی واقعی قابل آزمایش کامل نیست.
- موقعیت بر اساس فریم‌هایی است که callback به دستگاه صوتی تحویل می‌دهد؛ تأخیر داخلی خود دستگاه ممکن است اختلاف کوچکی با صدای شنیده‌شده ایجاد کند.
- اکولایزر فعلی نسخه توسعه‌ای است و برای استفاده حرفه‌ای به آزمون شنیداری، بهینه‌سازی DSP و مدیریت دقیق‌تر headroom نیاز دارد.
- Crossfade واقعی بین دو آهنگ هنوز پیاده‌سازی نشده است؛ این کار نیازمند رمزگشایی هم‌زمان دو منبع و میکس دو جریان صوتی است و باید جداگانه اضافه و تست شود.
- برای انتشار نهایی، تست طولانی‌مدت، انتخاب دستگاه خروجی، ذخیره تنظیمات، مدیریت فایل خراب و بسته‌بندی نصب‌کننده پیشنهاد می‌شود.
