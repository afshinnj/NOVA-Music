# NOVA Music 8

پخش‌کنندهٔ موسیقی محلی ویندوز با کتابخانهٔ SQLite، موتور PCM، اکولایزر و پیشنهاددهندهٔ آفلاین Smart DJ.

## امکانات

- رابط تیره با PySide6، جستجو، علاقه‌مندی‌ها و اسکن پوشه
- پوستهٔ تیرهٔ الهام‌گرفته از پلیرهای موسیقی، آیکون‌های SVG یکدست و آیکون اختصاصی برنامه (`nova_music/assets/`)
- نمایش کاورهای جاسازی‌شده در فهرست آهنگ‌ها، Smart DJ، تاریخچه و پلیر فعلی
- تغییر نوع نمایش کتابخانه و علاقه‌مندی‌ها بین فهرست و گرید کاورمحور، با ذخیره‌شدن انتخاب کاربر و کاور پیش‌فرض برای آهنگ‌های بدون کاور
- کارت گرید با کاور بزرگ و دکمه‌های سریع پخش و علاقه‌مندی هنگام بردن نشانگر روی کارت
- پنل بازشوندهٔ «در حال پخش» با کاور بزرگ و اطلاعات آهنگ؛ انتخاب تم روشن یا تیره با رنگ‌های خوانا
- مرتب‌سازی کتابخانه بر اساس عنوان، هنرمند، آلبوم، سال و مدت؛ فیلتر هم‌زمان بر اساس هنرمند، آلبوم و سبک موسیقی

- ویرایش عنوان، هنرمند، آلبوم، سبک، سال، شمارهٔ قطعه و کاور در فایل صوتی از منوی راست‌کلیک هر آهنگ
- صف پخش قابل‌ویرایش با افزودن آهنگ به انتهای صف یا پخش بعدی و تغییر ترتیب آهنگ‌ها
- ساخت و ذخیرهٔ پلی‌لیست‌های محلی؛ افزودن آهنگ از منوی راست‌کلیک و بارگذاری دوباره در اجراهای بعدی
- واردکردن و خروجی پلی‌لیست‌ها با قالب M3U؛ پشتیبانی از مسیرهای نسبی و گزارش مسیرهای مفقود

- بازیابی آهنگ، محل پخش و صف آخر هنگام اجرای دوباره؛ ادامه با فشردن دکمهٔ پخش
- نگه‌داشتن رکورد آهنگ‌های مفقودشده، اسکن پوشه برای اتصال خودکار فایل‌های جابه‌جا‌شده و امکان اتصال دستی
- اسکن کتابخانه برای یافتن نسخه‌های بایت‌به‌بایت یکسان؛ گزارش گروه‌ها بدون حذف یا تغییر فایل
- پایش خودکار پوشه‌های موسیقی در پس‌زمینه و افزودن موارد جدید به کتابخانه


- پخش، مکث، جلو و عقب، تکرار، Shuffle و اکولایزر ۱۰ بانده
- انتخاب خروجی صوتی و Crossfade قابل‌تنظیم از ۰ تا ۱۲ ثانیه
- رمزگشایی محلی با FFmpeg و نمایش طیف زنده
- Smart DJ با حالت‌های Favorites، Balanced و Discovery
- ثبت محلی شروع، مکث، ادامه، زمان واقعی شنیدن، تکمیل، رد، توقف و علاقه‌مندی‌ها
- امتیازدهی تدریجی و قابل‌توضیح با کاهش اثر تکرار و پخش‌های قدیمی
- پروفایل ژانر، خواننده و آلبوم، نمایش تاریخچه و آهنگ‌های بیشتر شنیده‌شده/ردشده
- تنظیم تنوع صف، حذف پیشنهاد و افزودن سریع آن به علاقه‌مندی‌ها

## پیش‌نیازها

- Python 3.12 یا جدیدتر
- FFmpeg در `PATH` یا فایل محلی `nova_music/bin/*/bin/ffmpeg.exe`
- دستگاه خروجی صوتی ویندوز

## نصب و اجرا (PowerShell)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## استفاده از Smart DJ

1. آهنگ‌ها را از صفحهٔ کتابخانه اضافه کن. ژانر، سال و شمارهٔ قطعه از برچسب فایل خوانده می‌شوند؛ برای اصلاح دستی روی آهنگ راست‌کلیک کن.
2. وارد صفحهٔ Smart DJ شو و حالت Favorites، Balanced یا Discovery را انتخاب کن.
3. میزان تنوع را تنظیم و «ساخت / بازسازی صف» را بزن. تحلیل در پس‌زمینه انجام می‌شود و آهنگ فعلی قطع نمی‌شود؛ صف هوشمند پس از آن پخش خواهد شد.
4. روی پیشنهاد دوبار کلیک کن تا همان آهنگ پخش شود؛ از دکمه‌ها یا منوی راست‌کلیک برای علاقه‌مندی و حذف پیشنهاد استفاده کن.

ثبت تاریخچه به‌طور پیش‌فرض فعال است و فقط در پایگاه دادهٔ محلی کاربر ذخیره می‌شود (`%LOCALAPPDATA%\NOVA Music\library.sqlite3`). خاموش‌کردن ثبت، تاریخچهٔ قبلی را نگه می‌دارد؛ دکمهٔ «پاک‌کردن تاریخچه» آن را حذف می‌کند. شنیدن بر اساس فریم‌های تحویل‌شده به خروجی صوتی محاسبه می‌شود، نه جابه‌جایی نوار Seek. زمان شنیدن دوره‌ای ذخیره می‌شود تا با بسته‌شدن ناگهانی برنامه از دست نرود.

مهاجرت Smart DJ فقط ستون‌ها، جدول‌ها و ایندکس‌های افزایشی می‌سازد؛ جدول کتابخانهٔ موجود بازسازی یا پاک نمی‌شود.

## محدودیت‌ها

- برای فایل‌های بدون برچسب ژانر، سبک حدس زده نمی‌شود و در آمار جداگانه شمرده می‌شوند.
- وزن‌ها و نیمه‌عمر ترجیحات در `nova_music/smart_dj/recommender.py` تنظیم‌پذیرند و نقطهٔ شروع تجربی هستند، نه معیار علمی.
- برای استفاده از Crossfade، آهنگ بعدی باید در صف پخش باشد.
